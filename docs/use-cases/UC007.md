# UC007 — Cấu hình tham số hệ thống

**Status:** Analyzed · **Module:** Chung (dependency, minimal) · **Priority:** H · **Rollout:** Đợt 1
Source: `usecases.txt` lines 1860–1898. FR-ADM-05 (as listed in the spec for this UC).

## 1. Objective
Store and read the operating parameters used by M1 and M2: ETA deviation threshold, berth safety buffer, AI timeout. Changes take effect on the next processing run.

## 2. Actors
- **Primary:** Quản trị hệ thống.
- **Supporting:** none.

## 3. Permissions
- Read: services only (internal). Administrators see values through the admin screen (out of scope).
- Change: `QUAN_TRI_HE_THONG` only (screen out of scope; seeded).

## 4. Preconditions
- The administrator is logged in (UC-001).

## 5. Postconditions
- **Success:** the new value is stored and used by the next run; the before and after values are audited.
- **Failure:** the previous value remains.

## 6. Main flow
1. The administrator opens the parameter list (current and default values).
2. The administrator edits a value and saves.
3. The API checks type and range.
4. The API saves, audits, and the next run reads the new value.

## 7. Alternative flows
- **4a. Changing an important parameter:** confirmation required (frontend).

## 8. Exception flows
- **3a. Value outside the allowed range or wrong type:** rejected with `VALIDATION_FAILED`.

## 9. Business rules
- **BR-1** Default values come from the specification and are seeded: `ETA_DEVIATION_THRESHOLD_H = 6` (FR-VES-06), `BERTH_SAFETY_BUFFER_M = 15` (BR-02), `AI_TIMEOUT_MS = 10000` (UC-015 3a, UC-016, UC-027).
- **BR-2** A parameter is read at the start of each processing run, not cached across runs.
- **BR-3** No parameter is set to a value that the specification does not allow. Allowed ranges are not yet defined (see A-2).

## 10. Acceptance criteria
- AC-1 Parameters can be read with their current and default values. *(Table and seeds exist. Read path not implemented.)*
- AC-2 A change is applied on the next run. *(Pending: no run reads parameters yet in code.)*
- AC-3 A change is audited. *(Pending.)*

## 11. Assumptions and open items
| ID | Item | Rationale | Affected |
|---|---|---|---|
| A-1 | Parameter values are seeded from the specification. | The specification gives the defaults. | BR-1 |
| A-2 | **Allowed ranges are not defined.** The API will reject non-numeric values only, until ranges are approved. | `CLAUDE.md` §7 forbids arbitrary thresholds. Proposed ranges need business approval. | BR-3 |
| A-3 | `system_parameters` stores values as text with a declared type (`INT`, `DECIMAL`, `STRING`). | Keeps one table for all parameters. | Schema |

## 12. Demo scenario
1. Read the threshold. Expect 6.
2. Change the buffer to 20. Expect the next berth check to use 20.
